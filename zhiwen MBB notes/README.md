## 一条主线：7 + 2 步解决问题法

| 步骤 | 做什么 | 对应讲次 |
| --- | --- | --- |
| **第 0 步** | **思考动机**：老板为什么会提这个问题 | 第 1 讲 |
| 第 1 步 | 界定问题：用 SMART 明确边界 | 第 1 讲 |
| 第 2 步 | 拆解问题：议题树 + MECE | 第 1 讲 |
| 第 3 步 | 优先级排序：二八原则去除不重要议题 | 第 1 讲 |
| 第 4 步 | 制定计划：任务、责任人、deadline、甘特图 | 第 1 讲 |
| 第 5 步 | 开展分析：信息收集、市场规模测算、看穿数据 | 第 2 / 3 / 5 讲 |
| 第 6 步 | 总结提炼：可视化呈现与图表表达 | 第 4 / 6 讲 |
| 第 7 步 | 给出建议：故事线 + 汇报 PPT | 第 7 讲 |
| **第 8 步** | **落地行动方案**：谁做、何时做、怎么做 | 第 1 讲 |

> 只有 7+2 形成闭环，问题才会被真正推向解决，而不是留下一张"大家都鼓掌、一个月后什么都没变"的漂亮报告。

## 阅读建议

1. **想解决手头具体问题**：直接读第 1 讲，照着"动机 → 界定 → 拆解 → 排序 → 计划"走一遍。
2. **要做行业 / 市场研究**：第 2 讲（信息从哪来）+ 第 3 讲（市场有多大）连读。
3. **要出分析报告 / 汇报材料**：第 5 讲（看穿数据）→ 第 6 讲（图表怎么画）→ 第 7 讲（PPT 怎么排）。
4. **工具能力补强**：第 4 讲（Excel 与定性形象化）、第 6 讲（think-cell）。
